# AI-Based Smart Water Tank Monitoring System

A lightweight simulation of a **model-based reflex agent** that monitors and
controls an overhead water tank. The project includes a **Java terminal simulation**
and a **browser-based UI** (HTML + JS) that mirror the same agent logic.

---

## 📁 Project Files

| File | Description |
|---|---|
| `SmartWaterTank.java` | Java terminal simulation — compile & run in any JDK environment |
| `smart_water_tank.html` | Interactive browser UI (AquaMind Monitor) — open directly in any browser |
| `README.md` | Project documentation (this file) |

> **Note:** `SmartWaterTank.class` and `SmartWaterTank$*.class` files are
> auto-generated by `javac` and can be safely deleted — they are recreated on
> every compile.

---

## ✨ Features

- **Model-based reflex agent** with hysteresis control (prevents rapid pump switching).
- **Gaussian sensor noise** simulated using the Box-Muller transform.
- **Stochastic household demand** (5–25 L/tick) and occasional source-dry events.
- **Live stats:** pump switches, overflow/shortage events, water-management score.
- **Animated tank UI** with emerald + violet dark theme, comparison level bars,
  pump status indicator, and live agent log table.
- **Fully simulated** — no hardware, no microcontrollers, no external packages.

## 🚀 Run — Java Terminal Simulation

1. Open a terminal in the project folder.
2. Compile:

```bash
javac SmartWaterTank.java
```

3. Run:

```bash
java SmartWaterTank
```

## 🌐 Run — Browser UI (AquaMind Monitor)

1. Open `smart_water_tank.html` in any modern browser.
   - Drag and drop it into Chrome/Edge, **or**
   - Paste the full file path into the browser address bar.
2. Click **▶ Start** to begin the live simulation.
3. Use the on-page sliders to adjust:
   - **Simulation speed** (tick interval in ms)
   - **Household demand max** (L/tick)
   - **Source dry probability** (%)
4. Click **⏸ Pause** to pause, **⟲ Reset** to restart.

## 🤖 How the Agent Works (PEAS)

| Component | Description |
|---|---|
| **Performance** | Maximize water availability, minimize overflow, shortage & pump switches |
| **Environment** | Virtual overhead tank with stochastic demand and optional source-dry |
| **Actuators** | Virtual motor relay (software flag: PUMP_ON / PUMP_OFF) |
| **Sensors** | Virtual ultrasonic level sensor with Gaussian noise (σ = 1.5%) |

**Decision logic (hysteresis):**
```
if   sensor_level ≤ 25%  →  PUMP ON
elif sensor_level ≥ 95%  →  PUMP OFF
else                      →  keep previous state  (model-based memory)
```

---

## 📊 Performance Score

```
score = 100 − (overflow_events + shortage_events) × 100 / total_ticks
```

A score of **100.0** means zero overflow and zero shortage events across all ticks.
