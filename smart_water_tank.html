How the Agent Works
① Sense Reads a Gaussian-noisy level percept every tick via virtual ultrasonic sensor.
② Decide Hysteresis rule: PUMP ON if level ≤ 25%, OFF if level ≥ 95%, else keep previous state.
③ Act Sends PUMP_ON / PUMP_OFF command to the virtual relay (software flag).
④ Update Environment applies stochastic demand (5–25 L), optional source-dry event, then physics-clamps the tank.
Runs entirely client-side in JavaScript — mirrors SmartWaterTank.java agent logic · zero physical sensors · zero microcontrollers
